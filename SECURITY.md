# Security Policy - CloudGuard AI

We take the security of CloudGuard AI seriously. If you believe you have found a security vulnerability in this project, please report it immediately as outlined below.

---

## 🔒 Supported Versions

Only the latest active release version of CloudGuard AI is supported for security updates:

| Version | Supported |
| --- | --- |
| v1.0.x | Yes |
| < v1.0.0 | No |

---

## ✉ Reporting a Vulnerability

Please do **NOT** open a public GitHub issue for security-related bugs or vulnerabilities.

Instead, report vulnerabilities via:
1. **Email**: Send a detailed security report to [security@cloudguard.ai](mailto:security@cloudguard.ai).
2. **Encrypted communication**: If desired, request our public PGP key via email to encrypt details.

### What to Include in the Report
To help us triage and resolve the issue quickly, please include:
- A clear description of the vulnerability and its potential impact.
- Step-by-step instructions to reproduce the vulnerability (proof-of-concept scripts or raw payloads).
- Details of the environment where it was tested.

---

## ⚡ Our Response Process

1. **Receipt & Triaging**: We will acknowledge receipt of your report within **48 hours** and verify the vulnerability.
2. **Remediation**: Once verified, we will work on a patch and coordinate a release.
3. **Public Disclosure**: We will publish a security advisory alongside the release tag. We practice responsible disclosure and appreciate keeping details private until a patch is released.
